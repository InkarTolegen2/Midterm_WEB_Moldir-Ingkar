Photography portfolio - a website for a small studio that shoots
weddings, portraits, and events. The idea was to keep it simple,
clean, and focused on the photos themselves.

## Short Description

Lens & Light is a multi-page portfolio website for a photography duo
based in Astana. The site shows who we are, what we shoot, our
pricing, and gives visitors an easy way to book a session. In the
endterm phase we added interactivity: real-time form validation,
dynamic search and filtering, a CRUD package manager, and an image
lightbox gallery.

---

## Features Implemented

### Midterm
- 5 connected pages: Home, About, Portfolio, Services, Contact
- Navigation bar visible on all pages (Flexbox)
- Photo gallery using CSS Grid with hover zoom + captions
- Pricing table with striped rows
- Booking form with HTML5 validation
- Sticky header
- Hero section with overlay
- Fully responsive (768px and 480px breakpoints)
- Bootstrap grid + utilities

### Endterm
- Registration page with real-time client-side validation
  (required fields, RegEx email, password strength meter,
  confirm-password match)
- Real-time search and category filter on the Portfolio page
- CRUD package manager on the Services page
  (Add / Edit / Delete via Bootstrap modal)
- Image lightbox on Portfolio with prev/next arrows,
  fade transitions, and keyboard navigation
- New folder: /js/script.js for all JavaScript

---

## Technologies Used

- HTML5 - semantic structure
- CSS3 - Flexbox, Grid, positioning, variables, pseudo-classes
- Bootstrap 5 - grid, utilities, modal component
- jQuery 3.7 - DOM manipulation, event handling, animations
- GitHub Pages - for publishing
