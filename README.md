## Short Description

Lens & Light is a 5-page portfolio website for a photography duo
based in Astana. The site shows who we are, what we shoot, our
pricing, and gives visitors an easy way to book a session.


---

## Features Implemented

- 5 connected pages: Home, About, Portfolio, Services, Contact
- Navigation bar visible on all pages (Flexbox)
- <header>, <main>, <footer> on every page
- Photo gallery using CSS Grid with hover zoom + captions
- Pricing table with striped rows (:nth-child())
- Booking form with HTML5 validation and :focus states
- Sticky header using position: sticky
- Hero section with absolute-positioned overlay
- Lazy loading on below-the-fold images
- Fully responsive: tablet (768px) and mobile (480px) breakpoints
- Bootstrap grid + utility classes for layout and spacing

## Technologies Used
